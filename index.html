Current holdings

How these numbers are calculated

  • Average purchase price = total cost of the shares you still hold ÷ number of shares held (a weighted average, so buying at different prices blends them).
  • Invested = sum of (quantity × average purchase price) over all holdings. Cash is never counted as invested.
  • Current value = quantity × sample price.
  • Unrealized P/L = current value − invested. "Unrealized" means the gain or loss is on paper only until you sell.
  • Portfolio value = virtual cash + current value of all holdings.
  • Sample prices are fixed, so P/L is ₹0.00 right after a purchase. It only changes if the sample prices in script.js are edited.
